# Cours Master CO S1

Site de mes cours du semestre 1, en ligne sur **https://kilian-beney.github.io/cours-master-co-s1/**

## Où est quoi

| Dossier | Page |
|---|---|
| `index.html` | Sommaire + agenda des rendus |
| `enquete/` | Techniques d'enquête |
| `audit/` | Audit et conseil en communication |
| `communication-scientifique/` | Communication scientifique |
| `droit/` | Droit de l'information et du numérique |
| `management/` | Management d'équipe |
| `radio/` | Radio |
| `veille/` | Veille stratégique et médiatique |

Chaque cours est un fichier `index.html` dans son dossier. Les images sont dans le sous-dossier `img/`.

## Modifier un cours (depuis le navigateur, rien à installer)

1. Ouvre le dossier du cours sur GitHub, puis le fichier `index.html`.
2. Clique sur le crayon ✏️ (« Edit this file ») en haut à droite.
3. Fais ta modification (Ctrl+F pour retrouver un passage).
4. Clique sur **Commit changes…** puis encore **Commit changes**.
5. Attends une minute : le site est à jour.

## Ajouter une image

Dans le dossier `img/` du cours : **Add file → Upload files**, puis dans le HTML :
`<img src="img/mon-image.jpg" alt="description">`
